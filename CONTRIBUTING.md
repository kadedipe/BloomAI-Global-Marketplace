# Contributing

1. Create a focused branch from current `main`.
2. Link the change to a Trello story or GitHub issue with acceptance criteria.
3. Add or update tests and documentation.
4. Run `make test` and `make lint` locally.
5. Open a pull request; do not merge until CI and code-owner review pass.

Use Conventional Commit-style messages where practical. Never commit secrets, datasets containing personal data, trained models without documented provenance, or generated files that cannot be reproduced.
